Deployment & Upgrade Manual for Combell Shared Webhosting (AsamblejaKombetare)
=============================================================================

IMPORTANT — PROTECTING EXISTING USERS & DATABASE CONTENT:
If you ALREADY have a database with registered users, ideas, core values, or
settings on Combell:
  - DO NOT import `database.sql` (that file is only for brand-new empty setups).
  - Your existing users and content are 100% preserved automatically! When you
    upload the updated PHP files, `includes/migrations.php` safely adds the new
    bilingual and password-reset columns without deleting or overwriting any
    existing rows. (Optionally, you can also run `upgrade.sql` in phpMyAdmin.)

-----------------------------------------------------------------------------
A. UPGRADING AN EXISTING COMBELL INSTALLATION (ZERO DATA LOSS)
-----------------------------------------------------------------------------

1. Take a Quick Backup (Recommended Best Practice)
   - In Combell Control Panel -> Databases -> phpMyAdmin, click the `Export`
     tab and download a `.sql` backup of your current database.

2. Create `includes/config.local.php` on the Server
   - Copy `includes/config.example.php` to `includes/config.local.php`.
   - Fill in:
     * `APP_URL`: `'https://yourdomain.com'` (no trailing slash)
     * `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`: your existing Combell MySQL
       credentials (previously in `includes/db.php`).
     * `SMTP_HOST`: `'smtp-auth.mailprotect.be'`
     * `SMTP_PORT`: `587` (or `2525`) with `SMTP_ENCRYPTION` = `'tls'`
     * `SMTP_USERNAME` & `SMTP_PASSWORD`: your Combell mailbox credentials
     * `SMTP_FROM_EMAIL`: same mailbox address (e.g. `'noreply@yourdomain.com'`)
     * `ADMIN_NOTIFICATION_EMAIL`: optional comma-separated email(s) to receive
       alerts on new registrations, ideas, and contact messages (if left empty,
       all approved admin accounts in the database are notified automatically).

3. Upload All Project Files via SFTP / File Manager
   - Upload all files and folders (including `.htaccess`, `uploads/.htaccess`,
     `includes/`, `vendor/`, `admin/`, and `assets/`) into your `www` directory
     on Combell. Make sure hidden dotfiles (`.htaccess`) are shown/uploaded in
     your FTP client (e.g. FileZilla -> Server -> Force showing hidden files).
   - Do NOT delete your existing `uploads/` folder on Combell so existing user
     profile pictures remain intact; only add `uploads/.htaccess` inside it.
   - Do NOT upload the `.git/` folder.

4. Verify Automatic Database Upgrade
   - Visit your website in a browser. `includes/migrations.php` will
     automatically add the new columns (`_sq` translations, `reset_token`,
     `full_name`, `party_role`, `bio`, `rate_limits`) while keeping all existing
     users, passwords, ideas, agreements, messages, and custom settings intact.
   - Log into `/admin/` using your admin **email address** and check the
     Dashboard for any security notices (such as updating a default password or
     placeholder admin email via `Change Email` / `Change Password`).

-----------------------------------------------------------------------------
B. FRESH INSTALLATION ON A BRAND-NEW EMPTY DATABASE
-----------------------------------------------------------------------------

1. Create a MySQL database and mailbox in the Combell Control Panel.
2. In phpMyAdmin, import `database.sql` into the empty database.
3. Copy `includes/config.example.php` to `includes/config.local.php` and enter
   your `APP_URL`, MySQL credentials, and Combell SMTP credentials.
4. Upload all project files (including `.htaccess` and `vendor/`, excluding
   `.git/`) to Combell's `www` directory.
5. Visit `https://yourdomain.com/login.php` and sign in with:
     Email:    admin@asamblejakombetare.al
     Password: password
6. Immediately click `Change Email` and `Change Password` in the Admin Dashboard
   to set your real administrator email and a strong unique password.
